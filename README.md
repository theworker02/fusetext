# fusetext

Fuse HTML/Markdown text fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/fusetext/

## Install / run

```bash
git clone https://github.com/theworker02/fusetext.git
cd fusetext
node src/cli.js
node --test
```
